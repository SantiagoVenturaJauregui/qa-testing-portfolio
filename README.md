# QA Testing Portfolio — SauceDemo

## Project overview

This repository contains a set of planned functional test cases for the SauceDemo web application. The cases cover login, inventory and product details, shopping cart behavior, and checkout validation.

- **Application:** [SauceDemo](https://www.saucedemo.com/)
- **Test types:** Functional, negative, UI, and regression testing
- **Environment:** Web browser
- **Execution status:** Not Run

## Repository structure

```text
qa-saucedemo-portfolio/
├── README.md
└── test-cases/
    └── ecommerce-functional-test-cases.md
```

## How to use this project

1. Open the application at https://www.saucedemo.com/.
2. Execute each test case using the documented steps.
3. Record the actual result, status, and execution date.
4. If a reproducible defect is found, document it separately with steps to reproduce and expected versus actual results.

**Integrity note:** All test cases are planned. Do not mark a test as Pass or Fail until it has actually been executed.
